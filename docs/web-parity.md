# Соответствие сайту

Эталон — Flask/Preact в `wiring`, пользовательские страницы из `src/features/`, `src/router/`, `legal_pages.py` и `public/styles.css`. Все мобильные страницы — React Native. Общий сайт внутри WebView не используется. Одна реализация работает на iOS и Android.

| Сайт | Нативная реализация | Общий сервер |
|---|---|---|
| Главная | `app/index.tsx` | Сессия `/api/me` |
| Вход, регистрация, почта, пароль | `src/ui/AuthScreen.tsx`, `src/features/auth/` | `/api/register`, `/api/auth/token`, `/api/email/*`, `/api/password/*`, серверный OAuth |
| Анкета и настройка после регистрации | `app/edit-profile.tsx`, `app/onboard.tsx` | `/api/me`, `/api/photos`, `/api/onboard/skip` |
| Лента | `src/features/feed/` | `/api/feed?limit=2`, `/api/feed/view`, `/api/swipe`, `/api/feed/reset` |
| Для тебя | Тот же нативный экран карточек | `/api/recommendations`, `/api/me/jev-feed`, `/api/premium/redeem` |
| Лайки | `app/(tabs)/likes.tsx` | `/api/likes`, отдельные фильтры и пять сортировок |
| Чаты и переписка | `app/(tabs)/chats.tsx`, `app/chat/[id].tsx`, `src/features/chat/` | `/api/matches`, `/api/messages/*`, `/api/unmatch` |
| Профиль человека / свой предпросмотр | `app/person/[id].tsx`, `src/ui/ProfileView.tsx` | `/api/people/:id`, like/pass/snooze, block/report/unmatch |
| Архив | `app/archive.tsx` | `/api/archive` |
| Видимость, согласия, уведомления, WIRING+ | Соответствующие `app/*.tsx` | Существующие `/api/me`, `/api/me/consents`, `/api/notifications`, `/api/plus` |
| Приглашения, удаление, поддержка | `app/invite.tsx`, `app/delete-account.tsx`, `app/support.tsx` | Тот же referral URL, `/api/me/delete`, `/support` |
| Правила, конфиденциальность, защита детей, удаление данных, рассылка, словарь | `src/ui/LegalScreen.tsx`, `src/content/*.json` | Текст скопирован из `legal_pages.py` и `glossary.py` |

Лента прокручивается вертикально, фотографии горизонтально. Прокрутка не отправляет like/pass; скрытие подтверждается. Карточки и позиция сохраняются внутри текущей сессии. Блокировки, жалобы и удаление из чатов используют общий серверный жизненный цикл без удаления строк сообщений.

Те же шрифты Fraunces и IBM Plex Sans, пять тем из CSS сайта (`src/themeTokens.ts`). У приложений нет отдельного переключателя light/dark. Юридические тексты — снимок источника: при изменении документов на сайте обновить JSON в приложениях.

## Проверено и что остаётся

TypeScript, lint, 23 модульных теста и экспорт Hermes-бандлов для iOS/Android проходят. Тесты покрывают транспорт, refresh, URL, фильтры, сортировку, состояние ленты, порядок и восстановление автосохранения. Серверная проверка включает OAuth PKCE, срок действия/повторный обмен, подтверждение почты, поддержку и ассоциации ссылок.

**Визуальное совпадение всех экранов и работа на устройствах ещё не подтверждены.** Локальная native-сборка остановилась при установке CocoaPods/JDK: на диске менее 300 МБ. Не выполнены скриншоты и сравнение страниц, VoiceOver/TalkBack, системные разрешения, запись/воспроизведение на устройствах, OAuth через настоящего провайдера и push. Их нельзя считать проверенными по одному успешному экспорту JS.

Перед выпуском:

1. Освободить место для Xcode/Android-сборок и симуляторов; завершить CocoaPods/JDK.
2. Установить обе платформенные сборки против локального API и локальных аккаунтов из README `wiring`.
3. Сравнить каждую строку таблицы с мобильной шириной сайта, включая все пять тем, клавиатуру, фото и длинные тексты; устранить найденные отличия.
4. Пройти общие сценарии: лайк → мэтч → текст/фото/голосовое → ответ/изменение/удаление → unmatch; проверить архив, отказ сети и возобновление.
5. Серверу нужны изменения из `codex/native-parity-api`: native OAuth exchange, native email tokens, bearer на `/support` и ассоциации ссылок. До их выкладки новые native auth-сценарии против production API не готовы.
6. Для Android App Links задать серверный `ANDROID_APP_LINK_SHA256` публичным SHA-256 сертификата подписи приложения. EAS projectId и APNs/FCM по-прежнему требуются для push.

Административные страницы Flask остаются веб-инструментом администраторов; в приложение для участников не переносились.

Expo Doctor: 20 из 21 проверки проходят; оставшаяся — отсутствующий CocoaPods. Это ограничение локального toolchain, а не подтверждение готовности IPA/APK.
